# Topic icon sources

Every icon's download address and destination link is recorded in [topics.json](../data/topics.json). These are topic and ecosystem references; logos belong to their respective owners.

- Development logos: [Devicon](https://github.com/devicons/devicon), [MIT license notice](DEVICON-LICENSE.txt).
- Brand icons: [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under CC0; individual brand marks retain their respective trademark rights.
- Base: [official Base brand kit](https://github.com/base/brand-kit/tree/main/logo/TheSquare/Digital).
- Arc: [official Arc website](https://www.arc.io), website icon.
- Circle: [official Circle website](https://www.circle.com), website icon.
- Robinhood Chain: [official compact feather symbol](https://docs.robinhood.com/chain/brand-guidelines/), used unmodified from its asset pack.

The gallery is separate from the core technical stack. The profile's four emphasized languages are Python, Java, TypeScript and Solidity.

## Printed folio fonts and frames

The folio embeds subsets of these open fonts. Source families are from Google Fonts; static masters and per-plate WOFF2 subsets are generated with fontTools.

- Bodoni Moda: [source](https://github.com/google/fonts/tree/main/ofl/bodonimoda), [SIL OFL license](../assets/fonts/licenses/bodonimoda-OFL.txt).
- Archivo: [source](https://github.com/google/fonts/tree/main/ofl/archivo), [SIL OFL license](../assets/fonts/licenses/archivo-OFL.txt).
- JetBrains Mono: [source](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono), [SIL OFL license](../assets/fonts/licenses/jetbrainsmono-OFL.txt).
- Noto Serif SC: [source](https://github.com/google/fonts/tree/main/ofl/notoserifsc), [SIL OFL license](../assets/fonts/licenses/notoserifsc-OFL.txt).

`assets/film/frame-*.jpg` are stills from the owner's existing public Script to Video showcase. `assets/film/omniai-diorama.jpg` shows the owner's public omniAI scene. These remain separate from any private video reference material.
